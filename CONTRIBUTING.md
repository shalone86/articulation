# Contributing

Thanks for wanting to help! Angelio is a family project: free learning games for kids at
[angelio.org](https://angelio.org).

- **Found a bug or a mistake in a question?** Open an issue with the level and what you saw.
  Wrong answers in kids' content matter to us, so these are especially welcome.
- **Want to fix something?** Fork, make the change, run `npm test`, and open a pull request.
  Keep it small and say what you tested (a phone screenshot helps).
- **Style:** plain HTML, CSS and ES modules, no build step and no framework. Everything a child
  needs is read aloud; tap targets are big; mistakes get a hint, then the answer.
- **Making your own app?** Start from the template:
  [shalone86/app-template](https://github.com/shalone86/app-template).
